# 本命太岁星君查询系统

这是一个基于网页的本命太岁星君查询系统，可以根据用户的出生年份和立春前后，查询对应的太岁星君信息。

## 功能特点

- 支持1924-2043年的生肖查询
- 考虑立春前后的年份计算
- 显示完整的太岁信息（生肖、干支、纳音等）
- 展示太岁星君图像

## 特殊说明

- 1924年立春前的情况特殊处理为1983年
- 其他年份立春前的情况按输入年份-1处理
- 立春后的情况按输入年份处理

## 使用方法

1. 选择出生年份（1924-2043）
2. 选择是立春前还是立春后出生
3. 点击"查看你的本命太岁星君"按钮
4. 查看结果页面显示的太岁信息

## 技术栈

- HTML5
- CSS3
- JavaScript
- Python (用于本地服务器)

## 本地运行

1. 确保系统已安装 Python
2. 在项目目录下运行：
   ```bash
   python -m http.server 8000
   ```
3. 在浏览器中访问：`http://localhost:8000`

## 文件结构

- `index.html`: 主页面
- `style.css`: 样式文件
- `script.js`: JavaScript 逻辑
- `output.json`: 太岁数据文件
